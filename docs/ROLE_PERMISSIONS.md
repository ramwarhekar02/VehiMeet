# ROLE_PERMISSIONS

## Customer
- Manage own profile
- Create and view own bookings
- Cancel own bookings
- View own KYC and tracking data

## Partner
- Manage own profile and attached vehicle
- Update availability and location
- View assigned bookings
- Accept, reject, start, and complete assigned trips

## Admin
- View dashboards and reports
- View all users, partners, and bookings
- Approve partners
- Review KYC sessions
- Assign bookings
