# USER_FLOWS

## Customer
1. Register or log in.
2. Browse vehicles.
3. Create booking with route data.
4. Complete KYC when required.
5. Track ride progress.
6. View history or cancel eligible bookings.

## Partner
1. Onboard and wait for approval.
2. Attach and manage vehicle.
3. Go online or offline.
4. Accept or reject assignments.
5. Start and complete trips.
6. Send live location updates.

## Admin
1. Review partner onboarding.
2. Approve partners and monitor vehicles.
3. Review KYC outcomes.
4. Assign bookings manually when needed.
5. Track system metrics and recent activity.
